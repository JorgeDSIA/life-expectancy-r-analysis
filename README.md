# Life Expectancy Analysis Using R

### Statistical Analysis, Data Visualization and Predictive Modeling

## Project Overview

This project explores life expectancy indicators using R, combining exploratory data analysis, statistical visualization, multivariate analysis, and predictive modeling.

The analysis is based on the **Life Expectancy (WHO)** dataset available through Kaggle, covering the period 2000–2015.

The project includes original R scripts, an improved analysis script, and a reproducible R Markdown report.

## Dataset

- **Source:** [Life Expectancy (WHO) — Kaggle](https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who)
- **Observations:** 2,938
- **Variables:** 22
- **Period:** 2000–2015
- **Format:** CSV

## Analytical Methods

- Data cleaning and transformation
- Exploratory Data Analysis (EDA)
- Statistical visualization using ggplot2
- Correlation analysis
- Principal Component Analysis (PCA)
- Multiple linear regression
- Logistic regression

## Reproducibility

The project uses the dataset located at:

`data/Life Expectancy Data.csv`

Run the analysis from the project's root directory. The scripts use relative paths to access the dataset.

The CSV loading step has been verified using R 4.5.1. Full end-to-end execution of the analysis and report has not yet been validated.
